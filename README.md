# Coin Rate Tooltip

Клиентский Fabric-мод для серверов с «койнами» (HolyWorld и подобные). Показывает курс койна и переводит цену предмета в койнах прямо в тултипе на аукционе.

## Возможности

- Каждые 3 минуты автоматически отправляет `/exchange` (без показа в чате) и обновляет курс койна.
- Ответ сервера на `/exchange` скрывается из чата, чтобы не мешал.
- В тултипе предметов на аукционе добавляет две серые строки:
  - `Курс койна: 2.50 ✦`
  - `Цена в койнах: 12345 ✦`
- Цена определяется автоматически: если в описании предмета уже стоит значок койна — цена берётся как есть, иначе конвертируется по курсу (₽ / руб).

## Установка

1. Скачайте `coinrate-1.21.4.jar` из [Releases](../../releases).
2. Положите его в папку `mods` клиента (Fabric + Fabric API).

## Сборка из исходников

Требуется JDK 17+ и декомпилированный game jar (intermediary, 1.21.4).

```powershell
javac -d classes -cp <classpath> --release 17 -proc:none src/com/pirs/coinrate/*.java
jar cf coinrate-1.21.4.jar -C classes .
```

## Конфигурация

Конфигурации нет. Курс обновляется автоматически каждые 3 минуты после входа на сервер.
